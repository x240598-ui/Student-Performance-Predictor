==============================================================
 ABSTRACT
==============================================================

This project develops a machine learning model to predict the
academic Performance Index of students based on five measurable
study-related features: hours studied per day, previous exam
scores, participation in extracurricular activities, daily sleep
hours, and the number of sample question papers practised.

A Linear Regression model was trained on a publicly available
dataset of 10,000 student records. The model was evaluated using
four standard regression metrics — MAE, MSE, RMSE, and R² — and
deployed as an interactive Streamlit web application that enables
end-users to obtain instant performance predictions by entering
their study habits.

The project demonstrates the complete machine learning pipeline:
data loading, exploratory data analysis (EDA), preprocessing,
model training, evaluation, visualisation, and deployment.


==============================================================
 PROBLEM STATEMENT
==============================================================

Academic performance is influenced by a combination of personal
habits and prior knowledge. Students, teachers, and parents
often struggle to identify which factors have the most impact
on exam results. Manual assessment is subjective and time-
consuming, and interventions are frequently applied too late.

This project addresses the need for an automated, data-driven
system that can:
  1. Quantify the relationship between study habits and outcomes.
  2. Predict a student's likely performance score before exams.
  3. Provide actionable insight to improve study plans.


==============================================================
 OBJECTIVES
==============================================================

  1. Perform thorough EDA to understand the dataset structure,
     distributions, missing values, duplicates, and correlations.

  2. Pre-process the data (encode categorical variable, verify
     data quality) to make it suitable for machine learning.

  3. Train a Linear Regression model using an 80/20 train-test
     split with a fixed random seed for reproducibility.

  4. Evaluate model performance using MAE, MSE, RMSE, and R².

  5. Visualise key relationships: hours studied vs. performance,
     previous scores vs. performance, actual vs. predicted values,
     and a full feature correlation heatmap.

  6. Deploy the trained model as an interactive Streamlit web
     application for real-time single-student prediction.

==============================================================
 METHODOLOGY
==============================================================

Step 1 — Data Loading
  • Loaded CSV with pandas read_csv().
  • Verified shape: 10,000 rows × 6 columns.

Step 2 — Exploratory Data Analysis (EDA)
  • Checked data types, statistical summaries (mean, std, min/max).
  • Counted missing values → 0 found.
  • Counted duplicate rows → 0 found.

Step 3 — Preprocessing
  • Encoded 'Extracurricular Activities': Yes → 1, No → 0.
  • All other columns are already numeric.
  • No feature scaling required for Linear Regression when
    interpreting raw coefficients; all features are on
    comparable ordinal scales.

Step 4 — Feature / Target Definition
  • Features (X): all 5 input columns.
  • Target (y): Performance Index.

Step 5 — Train / Test Split
  • Used train_test_split(test_size=0.20, random_state=42).
  • Training set: 8,000 samples.
  • Test set    : 2,000 samples.

Step 6 — Model Training
  • Algorithm: sklearn.linear_model.LinearRegression.
  • Fit on X_train, y_train.
  • Learned one coefficient per feature + intercept.

Step 7 — Evaluation
  • Predicted y_pred on X_test.
  • Computed MAE, MSE, RMSE, R².

Step 8 — Visualisation
  • Scatter plot: Hours Studied vs Performance Index.
  • Scatter plot: Previous Scores vs Performance Index.
  • Scatter plot: Actual vs Predicted (with y = x reference line).
  • Heatmap: Pearson correlation matrix of all features.

Step 9 — Model Persistence
  • Saved model with joblib.dump() → linear_regression_model.pkl.

Step 10 — Deployment
  • Streamlit app loads the .pkl model.
  • User adjusts 5 sliders / radio buttons.
  • Predicted index displayed with colour-coded performance level.

==============================================================
 SIMPLE VIVA QUESTIONS AND ANSWERS
==============================================================

Q1.  What is Machine Learning?
A1.  Machine Learning (ML) is a branch of Artificial Intelligence
     in which a computer learns patterns from data and makes
     predictions or decisions without being explicitly programmed
     for each rule.

Q2.  What type of ML problem is this?
A2.  This is a Supervised Learning, Regression problem because
     we are predicting a continuous numeric output (Performance
     Index) from labelled training data.

Q3.  What is Linear Regression?
A3.  Linear Regression finds the best-fit straight line
     (or hyperplane in multiple dimensions) that minimises the
     sum of squared differences between the actual and predicted
     values. The equation is:
       y = b0 + b1·x1 + b2·x2 + … + bn·xn
     where b0 is the intercept and b1…bn are coefficients.

Q4.  Why did you choose Linear Regression for this project?
A4.  Because the dataset shows strong linear relationships between
     the features and the target (R² ≈ 0.989), it is interpretable,
     computationally fast, and ideal for a beginner project.

Q5.  What is an 80/20 train-test split?
A5.  We divide the dataset so that 80% (8,000 rows) are used to
     train the model and the remaining 20% (2,000 rows) are kept
     separate to evaluate how well the model generalises to
     unseen data.

Q6.  What is MAE?
A6.  Mean Absolute Error — the average of the absolute differences
     between actual and predicted values. It is in the same unit
     as the target and is easy to interpret.
     Formula: MAE = (1/n) · Σ |y_actual − y_predicted|

Q7.  What is RMSE and how does it differ from MAE?
A7.  Root Mean Squared Error is the square root of the average
     of squared errors. It penalises large errors more heavily
     than MAE, making it sensitive to outliers.
     Formula: RMSE = √( (1/n) · Σ (y_actual − y_predicted)² )

Q8.  What does R² (R-squared) represent?
A8.  R² measures the proportion of variance in the target variable
     that is explained by the model. A value of 1.0 means a
     perfect fit; 0 means the model is no better than predicting
     the mean. Our model achieves ~0.989, meaning it explains
     ~98.9% of the variance.

Q9.  Why did you encode 'Extracurricular Activities'?
A9.  Machine learning algorithms work with numbers. The column
     contained text values ("Yes"/"No"). We mapped Yes → 1 and
     No → 0 (binary/label encoding) so the model can process it.

Q10. What is overfitting?
A10. Overfitting occurs when a model learns the training data so
     well — including its noise — that it performs poorly on new,
     unseen data. We checked for this by evaluating on a
     separate test set. A high R² on both train and test sets
     indicates the model generalises well.

Q11. What is the purpose of random_state=42 in train_test_split?
A11. It fixes the random seed so the split is reproducible.
     Every time you run the code you get exactly the same
     training and test sets, making results comparable.

Q12. What libraries did you use and why?
A12. • pandas   — data loading and manipulation
     • numpy    — numerical computations
     • scikit-learn — ML algorithms and metrics
     • matplotlib / seaborn — data visualisation
     • joblib   — saving/loading the trained model
     • streamlit — building the interactive web application

Q13. What is a correlation heatmap?
A13. It is a colour-coded grid that shows Pearson correlation
     coefficients between every pair of features. Values near
     +1 indicate strong positive correlation, near −1 strong
     negative correlation, and near 0 no linear relationship.

Q14. What is Streamlit?
A14. Streamlit is an open-source Python library that converts
     a plain Python script into a shareable, interactive web
     application with minimal code — no HTML, CSS, or JavaScript
     knowledge required.

Q15. How would you improve this model?
A15. Possible improvements include:
     • Trying non-linear models (Random Forest, XGBoost).
     • Adding more features (attendance, parental education).
     • Collecting more diverse data.
     • Using cross-validation instead of a single train/test split.
     • Applying feature engineering or polynomial features.
